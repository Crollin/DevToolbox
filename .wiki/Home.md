# DevToolbox - Wiki

Bienvenue dans le wiki de **DevToolbox**, votre boîte à outils développeur centralisée !

## À propos

DevToolbox est une plateforme personnelle développée par **Creactiveweb** pour centraliser, organiser et lancer rapidement tous vos outils de développement web. Cette application regroupe une collection complète d'outils pratiques pour les développeurs WordPress et web.

## Fonctionnalités principales

### Architecture moderne

- **Frontend** : Application React/Vite avec TypeScript
- **Backend** : API REST Node.js/Express
- **Base de données** : SQLite (légère et performante)
- **Déploiement** : Docker Compose pour un déploiement facile

### Outils disponibles

DevToolbox regroupe **15 outils** organisés en 5 catégories :

1. **Utilitaires** (6 outils) - Outils pratiques du quotidien
2. **Scripts** (3 outils) - Bibliothèques de code et scripts
3. **Commandes** (3 outils) - Glossaires de commandes CLI
4. **Convertisseurs** (1 outil) - Conversion et manipulation de données
5. **Génération** (1 outil) - Outils de génération

### Démarrage rapide

```bash
# Avec Docker (recommandé)
docker-compose up -d

# Accès
# Frontend : http://localhost
# Backend API : http://localhost:3000
```

Pour plus de détails, consultez le [Guide d'installation](Installation).
