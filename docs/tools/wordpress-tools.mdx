# WordPress Tools

Guide d'utilisation des outils WordPress dans DevToolbox (WP-CLI, Hooks, Queries, Scripts).

## Description

Les outils WordPress regroupent plusieurs fonctionnalités pour travailler avec WordPress :
- **WP-CLI Glossary** : Glossaire de commandes WP-CLI
- **WP Hook Reference** : Référence complète des hooks WordPress
- **WP Query Builder** : Constructeur visuel de requêtes WP_Query
- **WP Script Library** : Bibliothèque de scripts PHP/Shell WordPress

## WP-CLI Glossary

### Description

Glossaire de commandes WP-CLI avec catégories, favoris et recherche rapide.

### Fonctionnalités

- Collection de commandes WP-CLI
- Catégorisation (Posts, Users, Options, etc.)
- Recherche rapide
- Favoris
- Exemples d'utilisation

### Utilisation

1. Accédez à `/tools/wpcli-glossary`
2. Recherchez une commande
3. Cliquez sur une commande pour voir les détails
4. Ajoutez vos propres commandes

### Exemples de commandes

```bash
# Lister les articles
wp post list

# Créer un article
wp post create --post_title="Mon article" --post_status=publish

# Mettre à jour WordPress
wp core update

# Vider le cache
wp cache flush
```

## WP Hook Reference

### Description

Référence complète des hooks WordPress (actions et filtres) avec recherche, catégories et exemples.

### Fonctionnalités

- Base de données de hooks WordPress
- Recherche par nom, catégorie, tags
- Filtres par type (action/filtre)
- Exemples de code
- Favoris

### Utilisation

1. Accédez à `/tools/wp-hook-reference`
2. Recherchez un hook
3. Filtrez par type (action/filtre) ou catégorie
4. Cliquez sur un hook pour voir les détails

### Exemples de hooks

#### Actions

```php
// Hook init
add_action('init', 'ma_fonction');

function ma_fonction() {
    // Code exécuté après l'initialisation de WordPress
}
```

#### Filtres

```php
// Filtrer le contenu
add_filter('the_content', 'ma_fonction');

function ma_fonction($content) {
    return $content . '<p>Texte ajouté</p>';
}
```

## WP Query Builder

### Description

Constructeur visuel de requêtes WP_Query avec prévisualisation du code PHP généré.

### Fonctionnalités

- Interface visuelle pour construire des requêtes
- Prévisualisation du code PHP
- Sauvegarde de requêtes
- Export du code généré

### Utilisation

1. Accédez à `/tools/wp-query-builder`
2. Utilisez l'interface pour construire votre requête
3. Prévisualisez le code PHP généré
4. Sauvegardez la requête pour réutilisation
5. Copiez le code pour l'utiliser dans votre thème/plugin

### Exemple de requête générée

```php
$args = array(
    'post_type' => 'post',
    'posts_per_page' => 10,
    'orderby' => 'date',
    'order' => 'DESC',
    'meta_query' => array(
        array(
            'key' => 'custom_field',
            'value' => 'value',
            'compare' => '='
        )
    )
);

$query = new WP_Query($args);

if ($query->have_posts()) {
    while ($query->have_posts()) {
        $query->the_post();
        // Afficher le contenu
    }
    wp_reset_postdata();
}
```

## WP Script Library

### Description

Bibliothèque de scripts PHP/Shell pour WordPress avec catégorisation, tags et export.

### Fonctionnalités

- Gestion de scripts PHP/Shell
- Catégorisation (Maintenance, Migration, etc.)
- Tags pour la recherche
- Export de scripts
- Favoris

### Utilisation

1. Accédez à `/tools/wp-script-library`
2. Créez ou importez des scripts
3. Organisez par catégories
4. Exportez vos scripts

### Exemples de scripts

#### Script de maintenance

```php
<?php
// Désactiver tous les plugins
$plugins = get_option('active_plugins');
update_option('active_plugins', array());
```

#### Script de migration

```php
<?php
// Migrer des données
$posts = get_posts(array('post_type' => 'old_type'));
foreach ($posts as $post) {
    // Migration
}
```

## API Backend

Les outils WordPress sont gérés via l'API backend :

### WP-CLI
- `GET /api/wpcli` - Liste toutes les commandes
- `POST /api/wpcli` - Crée une commande
- `PUT /api/wpcli/:id` - Met à jour une commande
- `DELETE /api/wpcli/:id` - Supprime une commande

### Hooks
- `GET /api/hooks` - Liste tous les hooks
- `POST /api/hooks` - Crée un hook
- `PUT /api/hooks/:id` - Met à jour un hook
- `DELETE /api/hooks/:id` - Supprime un hook

### Queries
- `GET /api/queries` - Liste toutes les queries
- `POST /api/queries` - Crée une query
- `PUT /api/queries/:id` - Met à jour une query
- `DELETE /api/queries/:id` - Supprime une query

### Scripts
- `GET /api/scripts` - Liste tous les scripts
- `POST /api/scripts` - Crée un script
- `PUT /api/scripts/:id` - Met à jour un script
- `DELETE /api/scripts/:id` - Supprime un script

Pour plus de détails, consultez la [Référence API](/api-reference).
