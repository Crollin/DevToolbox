# Licence Key Hub

Guide d'utilisation du gestionnaire de clés de licence dans DevToolbox.

## Description

Licence Key Hub est un gestionnaire centralisé de clés de licence pour tous vos projets et applications SaaS. Organisez, suivez et gérez toutes vos licences en un seul endroit.

## Fonctionnalités

- **Gestion de licences** : Créez, modifiez et supprimez des licences
- **Suivi des statuts** : Suivez l'état de vos licences (active, expirée, etc.)
- **Dates d'expiration** : Gérez les dates d'expiration
- **Notifications** : Recevez des notifications pour les licences expirant bientôt
- **Organisation** : Organisez par type, fournisseur, tags
- **Recherche** : Trouvez rapidement une licence

## Utilisation

### Accéder au gestionnaire

1. Depuis la page d'accueil, cliquez sur "Licence Key Hub"
2. Ou accédez directement à `/tools/licence-key-hub`

### Créer une licence

1. Cliquez sur le bouton "Ajouter une licence"
2. Remplissez le formulaire :
   - **Nom** : Nom du produit/service
   - **Clé** : Clé de licence
   - **Type** : SaaS, Plugin, Theme, etc.
   - **Fournisseur** : Nom du fournisseur
   - **Statut** : Active, Expirée, Suspendue
   - **Date d'expiration** : Date d'expiration (optionnel)
   - **Notes** : Notes supplémentaires
   - **Tags** : Tags pour la recherche
3. Cliquez sur "Enregistrer"

### Modifier une licence

1. Cliquez sur une licence pour l'ouvrir
2. Cliquez sur le bouton "Modifier"
3. Modifiez les champs nécessaires
4. Cliquez sur "Enregistrer"

### Supprimer une licence

1. Ouvrez la licence
2. Cliquez sur le bouton "Supprimer"
3. Confirmez la suppression

### Filtrer les licences

Utilisez les filtres pour :
- **Statut** : Active, Expirée, Suspendue
- **Type** : SaaS, Plugin, Theme, etc.
- **Fournisseur** : Filtrer par fournisseur
- **Recherche** : Rechercher par nom, clé, tags

### Notifications

Les licences expirant bientôt sont marquées avec un indicateur visuel. Configurez les notifications dans les paramètres.

## Statuts de licence

- **Active** : Licence valide et active
- **Expirée** : Licence expirée
- **Suspendue** : Licence suspendue
- **En attente** : Licence en attente d'activation

## Types de licences

- **SaaS** : Services SaaS (ex: GitHub, Netlify)
- **Plugin** : Plugins WordPress
- **Theme** : Thèmes WordPress
- **Software** : Logiciels
- **API Key** : Clés API
- **Autre** : Autres types

## API Backend

Les licences sont gérées via l'API backend :

- `GET /api/licences` - Liste toutes les licences
- `POST /api/licences` - Crée une licence
- `PUT /api/licences/:id` - Met à jour une licence
- `DELETE /api/licences/:id` - Supprime une licence

Pour plus de détails, consultez la [Référence API](/api-reference#licences).

## Astuces

1. **Organisation** : Utilisez les tags pour organiser vos licences
2. **Dates** : Ajoutez toujours les dates d'expiration quand disponibles
3. **Notes** : Ajoutez des notes pour des informations supplémentaires
4. **Statut** : Mettez à jour le statut régulièrement
5. **Sécurité** : Ne partagez jamais vos clés de licence

## Sécurité

<Warning>
**Important** : Les clés de licence sont sensibles. Assurez-vous que :
- La base de données est sécurisée
- Les accès sont limités
- Les sauvegardes sont chiffrées
- Vous ne partagez jamais vos clés
</Warning>
