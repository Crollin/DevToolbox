# Color Palette Gen

Guide d'utilisation du générateur de palettes de couleurs dans DevToolbox.

## Description

Color Palette Gen est un générateur de palettes de couleurs harmonieuses pour vos projets web et design. Créez, organisez et exportez vos palettes de couleurs avec des outils de prévisualisation et de vérification de contraste.

## Fonctionnalités

- **Génération de palettes** : Créez des palettes harmonieuses
- **Prévisualisation UI** : Visualisez vos couleurs dans une interface
- **Vérification de contraste** : Vérifiez l'accessibilité de vos couleurs
- **Export** : Exportez vos palettes en différents formats
- **Organisation** : Organisez vos palettes avec des tags
- **Favoris** : Marquez vos palettes favorites

## Utilisation

### Accéder au générateur

1. Depuis la page d'accueil, cliquez sur "Color Palette Gen"
2. Ou accédez directement à `/tools/color-palette-gen`

### Créer une palette

1. Cliquez sur le bouton "Ajouter une palette"
2. Remplissez le formulaire :
   - **Nom** : Nom de la palette
   - **Description** : Description de la palette
   - **Couleurs** : Ajoutez des couleurs (nom, hex, RGB)
   - **Tags** : Tags pour la recherche
3. Cliquez sur "Enregistrer"

### Ajouter une couleur

1. Dans l'éditeur de palette, cliquez sur "Ajouter une couleur"
2. Entrez le nom de la couleur
3. Entrez la valeur hexadécimale (ex: `#3b82f6`)
4. La valeur RGB sera calculée automatiquement
5. Cliquez sur "Ajouter"

### Prévisualisation UI

La prévisualisation UI vous permet de voir comment vos couleurs fonctionnent ensemble dans une interface :

- **Header** : Utilise la couleur primaire
- **Boutons** : Utilisent les couleurs de la palette
- **Texte** : Utilise les couleurs de texte
- **Arrière-plan** : Utilise les couleurs de fond

### Vérification de contraste

L'outil de vérification de contraste vous aide à vérifier l'accessibilité :

1. Sélectionnez deux couleurs (texte et fond)
2. Le ratio de contraste sera calculé automatiquement
3. Un indicateur vous dira si le contraste est suffisant (WCAG AA/AAA)

### Exporter une palette

1. Ouvrez une palette
2. Cliquez sur "Exporter"
3. Choisissez le format :
   - **CSS Variables** : Variables CSS
   - **JSON** : Format JSON
   - **SCSS** : Variables SCSS
   - **Tailwind** : Configuration Tailwind

## Formats d'export

### CSS Variables

```css
:root {
  --primary: #3b82f6;
  --primary-rgb: 59, 130, 246;
  --secondary: #10b981;
  --secondary-rgb: 16, 185, 129;
}
```

### JSON

```json
{
  "name": "Ma palette",
  "colors": [
    {
      "name": "Primary",
      "hex": "#3b82f6",
      "rgb": "59, 130, 246"
    }
  ]
}
```

### SCSS

```scss
$primary: #3b82f6;
$primary-rgb: 59, 130, 246;
$secondary: #10b981;
$secondary-rgb: 16, 185, 129;
```

### Tailwind

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#3b82f6',
        secondary: '#10b981',
      }
    }
  }
}
```

## API Backend

Les palettes sont gérées via l'API backend :

- `GET /api/palettes` - Liste toutes les palettes
- `POST /api/palettes` - Crée une palette
- `PUT /api/palettes/:id` - Met à jour une palette
- `DELETE /api/palettes/:id` - Supprime une palette

Pour plus de détails, consultez la [Référence API](/api-reference#palettes-de-couleurs).

## Astuces

1. **Harmonie des couleurs** : Utilisez des outils de théorie des couleurs pour créer des palettes harmonieuses
2. **Accessibilité** : Vérifiez toujours le contraste pour l'accessibilité
3. **Nommage** : Utilisez des noms descriptifs pour vos couleurs
4. **Export** : Exportez dans le format adapté à votre projet
