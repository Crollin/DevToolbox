# Code Snippet Library

Guide d'utilisation de la bibliothèque de snippets de code dans DevToolbox.

## Description

La bibliothèque de snippets de code permet de gérer et organiser vos snippets de code avec support pour l'import/export WPCodeBox. Vous pouvez créer, modifier, organiser et exporter vos snippets pour les utiliser dans vos projets WordPress.

## Fonctionnalités

- **Gestion de snippets** : Créez, modifiez et supprimez des snippets
- **Organisation par dossiers** : Organisez vos snippets dans des dossiers
- **Tags** : Ajoutez des tags pour faciliter la recherche
- **Import/Export WPCodeBox** : Compatible avec WPCodeBox
- **Multi-langages** : Support de PHP, JavaScript, CSS, etc.
- **Scopes** : Définissez où le snippet doit s'exécuter (frontend, admin, etc.)
- **Priorité** : Définissez la priorité d'exécution
- **Activation/Désactivation** : Activez ou désactivez vos snippets

## Utilisation

### Accéder à la bibliothèque

1. Depuis la page d'accueil, cliquez sur "Code Snippet Library"
2. Ou accédez directement à `/tools/code-snippet-library`

### Créer un snippet

1. Cliquez sur le bouton "Ajouter un snippet"
2. Remplissez le formulaire :
   - **Titre** : Nom du snippet
   - **Description** : Description de ce que fait le snippet
   - **Code** : Le code du snippet
   - **Langage** : PHP, JavaScript, CSS, etc.
   - **Scope** : Frontend, Admin, ou les deux
   - **Priorité** : Priorité d'exécution (défaut: 10)
   - **Tags** : Tags pour la recherche
   - **Dossier** : Dossier d'organisation
   - **Actif** : Activez ou désactivez le snippet
   - **Run Once** : Exécuter une seule fois
3. Cliquez sur "Enregistrer"

### Modifier un snippet

1. Cliquez sur un snippet pour l'ouvrir
2. Cliquez sur le bouton "Modifier"
3. Modifiez les champs nécessaires
4. Cliquez sur "Enregistrer"

### Supprimer un snippet

1. Ouvrez le snippet
2. Cliquez sur le bouton "Supprimer"
3. Confirmez la suppression

### Organiser par dossiers

1. Créez un dossier en cliquant sur "Ajouter un dossier"
2. Assignez vos snippets à des dossiers lors de la création ou modification
3. Filtrez par dossier dans l'interface

### Importer depuis WPCodeBox

1. Cliquez sur "Importer"
2. Sélectionnez votre fichier d'export WPCodeBox (JSON)
3. Les snippets seront importés automatiquement

### Exporter vers WPCodeBox

1. Sélectionnez les snippets à exporter
2. Cliquez sur "Exporter"
3. Téléchargez le fichier JSON compatible WPCodeBox

## Scopes disponibles

- **Frontend** : Exécuté sur le frontend du site
- **Admin** : Exécuté dans l'administration WordPress
- **Both** : Exécuté partout

## Langages supportés

- PHP
- JavaScript
- CSS
- HTML
- Autres langages web

## Exemples de snippets

### Snippet PHP simple

```php
<?php
// Ajouter un texte personnalisé après le contenu
add_filter('the_content', function($content) {
    return $content . '<p>Texte personnalisé</p>';
});
```

### Snippet JavaScript

```javascript
// Désactiver le clic droit
document.addEventListener('contextmenu', function(e) {
    e.preventDefault();
});
```

## API Backend

Les snippets sont gérés via l'API backend :

- `GET /api/snippets` - Liste tous les snippets
- `GET /api/snippets/:id` - Récupère un snippet
- `POST /api/snippets` - Crée un snippet
- `PUT /api/snippets/:id` - Met à jour un snippet
- `DELETE /api/snippets/:id` - Supprime un snippet
- `POST /api/snippets/folders` - Ajoute un dossier
- `POST /api/snippets/tags` - Ajoute un tag

Pour plus de détails, consultez la [Référence API](/api-reference#snippets).

## Format d'export WPCodeBox

Le format d'export est compatible avec WPCodeBox :

```json
{
  "snippets": [
    {
      "id": "uuid",
      "title": "Mon snippet",
      "code": "<?php echo 'Hello'; ?>",
      "language": "php",
      "scope": "frontend",
      "priority": 10,
      "tags": ["wordpress"],
      "folder": "Custom",
      "active": true,
      "runOnce": false
    }
  ]
}
```

## Astuces

1. **Organisez par dossiers** : Créez des dossiers logiques (Custom, WPCodeBox, etc.)
2. **Utilisez les tags** : Ajoutez des tags pertinents pour faciliter la recherche
3. **Définissez la priorité** : Utilisez la priorité pour contrôler l'ordre d'exécution
4. **Testez avant d'activer** : Testez vos snippets avant de les activer en production
5. **Documentez** : Ajoutez des descriptions claires pour chaque snippet
