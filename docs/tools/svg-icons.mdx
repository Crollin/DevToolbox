# SVG Icon Library

Guide d'utilisation de la bibliothèque d'icônes SVG dans DevToolbox.

## Description

La bibliothèque d'icônes SVG permet de gérer, éditer et exporter vos icônes SVG. Vous pouvez créer des bibliothèques d'icônes personnalisées et les exporter en différents formats (SVG, JSX).

## Fonctionnalités

- **Gestion d'icônes** : Créez, modifiez et supprimez des icônes SVG
- **Éditeur SVG** : Éditez le code SVG directement
- **Prévisualisation** : Visualisez vos icônes avant export
- **Export multi-formats** : Exportez en SVG ou JSX
- **Recherche** : Trouvez rapidement une icône
- **Tags** : Organisez vos icônes avec des tags
- **Favoris** : Marquez vos icônes favorites

## Utilisation

### Accéder à la bibliothèque

1. Depuis la page d'accueil, cliquez sur "SVG Icon Library"
2. Ou accédez directement à `/tools/svg-icon-library`

### Créer une icône

1. Cliquez sur le bouton "Ajouter une icône"
2. Remplissez le formulaire :
   - **Nom** : Nom de l'icône
   - **Description** : Description de l'icône
   - **SVG** : Code SVG de l'icône
   - **Tags** : Tags pour la recherche
3. Cliquez sur "Enregistrer"

### Éditer une icône

1. Cliquez sur une icône pour l'ouvrir
2. Cliquez sur le bouton "Modifier"
3. Modifiez le code SVG dans l'éditeur
4. La prévisualisation se met à jour en temps réel
5. Cliquez sur "Enregistrer"

### Exporter une icône

1. Ouvrez une icône
2. Cliquez sur "Exporter"
3. Choisissez le format :
   - **SVG** : Fichier SVG brut
   - **JSX** : Composant React JSX

## Formats d'export

### SVG

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
  <path d="M12 2L2 7l10 5 10-5-10-5z"/>
</svg>
```

### JSX

```jsx
export const MonIcon = (props) => (
  <svg 
    xmlns="http://www.w3.org/2000/svg" 
    viewBox="0 0 24 24" 
    fill="none" 
    stroke="currentColor" 
    strokeWidth="2"
    {...props}
  >
    <path d="M12 2L2 7l10 5 10-5-10-5z"/>
  </svg>
);
```

## Bonnes pratiques SVG

1. **ViewBox** : Définissez toujours un viewBox approprié
2. **Dimensions** : Utilisez des dimensions cohérentes
3. **Couleurs** : Utilisez `currentColor` pour la couleur du trait/remplissage
4. **Optimisation** : Supprimez les attributs inutiles
5. **Accessibilité** : Ajoutez des attributs `aria-label` si nécessaire

## API Backend

Les icônes sont gérées via l'API backend :

- `GET /api/icons` - Liste toutes les icônes
- `POST /api/icons` - Crée une icône
- `PUT /api/icons/:id` - Met à jour une icône
- `DELETE /api/icons/:id` - Supprime une icône

Pour plus de détails, consultez la [Référence API](/api-reference#icônes-svg).

## Astuces

1. **Réutilisabilité** : Créez des icônes réutilisables avec `currentColor`
2. **Organisation** : Utilisez des tags pour organiser vos icônes
3. **Optimisation** : Optimisez vos SVG pour réduire la taille
4. **Cohérence** : Maintenez une cohérence dans le style de vos icônes
