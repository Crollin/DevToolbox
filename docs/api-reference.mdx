# Référence API

Documentation complète de l'API REST backend de DevToolbox.

## Vue d'ensemble

L'API backend de DevToolbox est une API REST qui expose des endpoints pour gérer tous les modules de l'application. Tous les endpoints retournent des réponses au format JSON.

## Base URL

- **Développement local** : `http://localhost:1400`
- **Docker** : `http://localhost:1400`
- **Production** : `https://votre-domaine.com:1400`

## Codes de réponse

| Code | Description |
|------|-------------|
| 200 | Succès |
| 201 | Créé avec succès |
| 400 | Requête invalide |
| 404 | Ressource non trouvée |
| 500 | Erreur serveur |

## Authentification

Tous les endpoints de données nécessitent une authentification JWT (sauf `/health`).

<Info>
Le token expire après 7 jours. Vous devrez vous reconnecter pour obtenir un nouveau token.
</Info>

### Obtenir un token

<Endpoint name="POST /api/auth/register" method="post" path="/api/auth/register">
  <Param name="email" type="string" required>
    Adresse email de l'utilisateur
  </Param>
  <Param name="name" type="string" required>
    Nom de l'utilisateur
  </Param>
  <Param name="password" type="string" required>
    Mot de passe
  </Param>

  <Response status="201">
    Crée un nouveau compte utilisateur et retourne un token JWT.
  </Response>
</Endpoint>

<Endpoint name="POST /api/auth/login" method="post" path="/api/auth/login">
  <Param name="email" type="string" required>
    Adresse email de l'utilisateur
  </Param>
  <Param name="password" type="string" required>
    Mot de passe
  </Param>

  <Response status="200">
    Connecte un utilisateur existant et retourne un token JWT.
  </Response>
</Endpoint>

<Endpoint name="GET /api/auth/me" method="get" path="/api/auth/me">
  <Param name="Authorization" type="header" required>
    Bearer token JWT
  </Param>

  <Response status="200">
    Récupère les informations de l'utilisateur actuel.
  </Response>
</Endpoint>

<Endpoint name="PUT /api/auth/change-password" method="put" path="/api/auth/change-password">
  <Param name="Authorization" type="header" required>
    Bearer token JWT
  </Param>
  <Param name="currentPassword" type="string" required>
    Mot de passe actuel
  </Param>
  <Param name="newPassword" type="string" required>
    Nouveau mot de passe
  </Param>

  <Response status="200">
    Change le mot de passe de l'utilisateur connecté.
  </Response>
</Endpoint>

### Utilisation du token

Pour utiliser les endpoints protégés, incluez le token dans le header `Authorization` :

```
Authorization: Bearer <votre-token-jwt>
```

## Exemples

### Exemple avec cURL

<CodeGroup>
```bash Login
# 1. S'inscrire ou se connecter pour obtenir un token
TOKEN=$(curl -X POST http://localhost:1400/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"motdepasse123"}' \
  | jq -r '.token')
```

```bash Get Snippets
# 2. Utiliser le token pour les requêtes protégées
# Récupérer tous les snippets
curl http://localhost:1400/api/snippets \
  -H "Authorization: Bearer $TOKEN"
```

```bash Create Snippet
# Créer un snippet
```

### Exemple avec JavaScript (Fetch)

```javascript
// 1. Se connecter pour obtenir un token
const loginResponse = await fetch('http://localhost:1400/api/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'motdepasse123'
  })
});
const { token } = await loginResponse.json();

// 2. Utiliser le token pour les requêtes protégées
// Récupérer tous les snippets
const response = await fetch('http://localhost:1400/api/snippets', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});
const data = await response.json();
console.log(data.snippets);
```

## Notes importantes

1. **Format des dates** : Toutes les dates sont au format ISO 8601 (UTC)
2. **IDs** : Les IDs sont des UUIDs v4
3. **Tags** : Les tags sont stockés sous forme de tableaux JSON
4. **Base de données** : SQLite est utilisée, donc toutes les opérations sont synchrones
5. **CORS** : CORS est activé pour permettre les requêtes depuis le frontend
6. **Authentification** : Tous les endpoints de données nécessitent une authentification JWT (sauf `/health`)
7. **Tokens JWT** : Les tokens expirent après 7 jours. Renouvelez votre session en vous reconnectant
8. **Données utilisateur** : Chaque utilisateur ne voit que ses propres données (isolation par `user_id`)
